# Clearlink 短链接系统接口文档

> 版本：v0.1
> 本文档由代码走查（gateway / admin / project 三个模块的 Controller 与 DTO）整理而成。
> 说明：本文档中的接口路径已将原系统的 `short-link/v1` 统一替换为 `clearlink/v0.1`（仅文档改名，代码未改动）。
> 原系统路径与新路径对应关系：`/api/short-link/.../v1/...` → `/api/clearlink/.../v0.1/...`。

---

## 1. 文档说明

### 1.1 部署与访问入口

| 项 | 值 |
| --- | --- |
| 网关（统一入口） | `http://localhost:8000` |
| 网关转发规则 | `/api/clearlink/admin/**` → admin 服务；`/api/clearlink/**` → project 服务 |
| 短链接跳转入口 | `http://<域名>:<端口>/{short-uri}`（不经网关 `/api` 前缀，直接访问 project） |

> 除「短链接跳转」和「不存在页面」外，其余接口均需通过网关访问。

### 1.2 认证方式

网关（`TokenValidate` 过滤器）对请求头进行鉴权：

| 请求头 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Token` | string | 是 | 登录后下发的 token |
| `Username` | string | 是 | 登录用户名 |

- 网关校验 `Redis Hash short-link:login:{username}` 中是否存在该 `token`；校验通过后自动在转发请求头中补充 `userId`、`realName`（URL 编码）。
- **免鉴权白名单**：
  - `POST /api/clearlink/admin/v0.1/user/login`（登录）
  - `GET /api/clearlink/admin/v0.1/user/has-username`（用户名查重）
  - `POST /api/clearlink/admin/v0.1/user`（注册）
- 其余接口未携带有效 `Token`/`Username` 将返回 `401 Unauthorized`。

### 1.3 统一响应结构

所有接口（除「跳转」「不存在页面」「批量创建导出」）均返回如下 JSON：

```json
{
  "code": "0",
  "message": null,
  "data": {},
  "requestId": null
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | string | 成功为 `"0"`，失败为错误码（见第 6 节） |
| `message` | string | 提示信息，成功时为空 |
| `data` | T | 业务数据，各接口不同 |
| `requestId` | string | 请求追踪 ID（当前实现未填充） |

> 判断成功与否请以 `code == "0"` 为准（`Result.isSuccess()`）。

### 1.4 分页参数约定

带分页的接口统一使用 `current`（当前页，从 1 开始）+ `size`（每页条数）两个查询参数，返回 `data` 为 MyBatis-Plus `Page/IPage` 结构（含 `records`、`total`、`current`、`size` 等字段）。

### 1.5 关于「必填」的说明

本项目请求 DTO **未使用 Bean Validation 注解**（如 `@NotBlank`、`@Size`），参数的必填性由业务代码判定。下文参数表中标注的「必填」为依据业务流程整理的结果，仅供参考；实际以服务端业务校验为准。

## 2. 管理端接口（admin，前缀 `/api/clearlink/admin/v0.1`）

### 2.1 用户管理

#### 2.1.1 用户注册

- **路径**：`POST /api/clearlink/admin/v0.1/user`
- **说明**：注册新用户，并自动创建「默认分组」。免鉴权。
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名（全局唯一，重复报错） |
| password | string | 是 | 密码 |
| realName | string | 否 | 真实姓名 |
| phone | string | 否 | 手机号（入库 AES 加密） |
| mail | string | 否 | 邮箱（入库 AES 加密） |

- **返回**：`Result<Void>`（无 data）。
- **错误**：用户名已存在 → `A000100` 系列 / `ClientException`。

#### 2.1.2 用户登录

- **路径**：`POST /api/clearlink/admin/v0.1/user/login`
- **说明**：校验用户名密码，成功后返回 token（有效 30 分钟）。免鉴权。
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

- **返回**：`Result<UserLoginRespDTO>`，`data` 字段 `token`（string）。

#### 2.1.3 检查登录状态

- **路径**：`GET /api/clearlink/admin/v0.1/user/check-login`
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| token | string | 是 | 登录 token |

- **返回**：`Result<Boolean>`，`data` 为是否已登录。

#### 2.1.4 退出登录

- **路径**：`DELETE /api/clearlink/admin/v0.1/user/logout`
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名 |
| token | string | 是 | 登录 token |

- **返回**：`Result<Void>`。

#### 2.1.5 查询用户信息（脱敏）

- **路径**：`GET /api/clearlink/admin/v0.1/user/{username}`
- **路径参数**：`username`（string，必填）。
- **返回**：`Result<UserRespDTO>`（手机号等敏感字段脱敏）。

#### 2.1.6 查询用户信息（不脱敏）

- **路径**：`GET /api/clearlink/admin/v0.1/actual/user/{username}`
- **路径参数**：`username`（string，必填）。
- **返回**：`Result<UserActualRespDTO>`（完整字段）。

#### 2.1.7 用户名是否存在

- **路径**：`GET /api/clearlink/admin/v0.1/user/has-username`
- **请求参数（Query）**：`username`（string，必填）。免鉴权。
- **返回**：`Result<Boolean>`，`data=true` 表示可注册（不存在）。

#### 2.1.8 修改用户信息

- **路径**：`PUT /api/clearlink/admin/v0.1/user`
- **说明**：仅允许修改当前登录用户本人（用户名与上下文一致）。
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名（须为当前登录用户） |
| password | string | 否 | 密码 |
| realName | string | 否 | 真实姓名 |
| phone | string | 否 | 手机号 |
| mail | string | 否 | 邮箱 |

- **返回**：`Result<Void>`。

### 2.2 分组管理

#### 2.2.1 新增分组

- **路径**：`POST /api/clearlink/admin/v0.1/group`
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 分组名称 |

- **返回**：`Result<Void>`。

#### 2.2.2 查询分组列表

- **路径**：`GET /api/clearlink/admin/v0.1/group`
- **返回**：`Result<List<ShortLinkGroupRespDTO>>`（`data` 为当前用户分组数组）。

#### 2.2.3 修改分组名称

- **路径**：`PUT /api/clearlink/admin/v0.1/group`
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| gid | string | 是 | 分组标识 |
| name | string | 是 | 新分组名 |

- **返回**：`Result<Void>`。

#### 2.2.4 删除分组

- **路径**：`DELETE /api/clearlink/admin/v0.1/group`
- **请求参数（Query）**：`gid`（string，必填）。
- **返回**：`Result<Void>`。

#### 2.2.5 分组排序

- **路径**：`POST /api/clearlink/admin/v0.1/group/sort`
- **请求体（application/json）**：数组，元素结构：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| gid | string | 是 | 分组标识 |
| sortOrder | int | 是 | 排序序号 |

- **返回**：`Result<Void>`。

### 2.3 短链接管理

#### 2.3.1 创建短链接

- **路径**：`POST /api/clearlink/admin/v0.1/create`
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| domain | string | 否 | 域名（服务端使用默认域名） |
| originUrl | string | 是 | 原始链接（受跳转域名白名单约束） |
| gid | string | 是 | 分组标识（分片键） |
| createdType | int | 否 | 创建类型：0=接口 1=控制台 |
| validDateType | int | 否 | 有效期类型：0=永久 1=自定义 |
| validDate | string | 否 | 有效期，格式 `yyyy-MM-dd HH:mm:ss` |
| describe | string | 否 | 描述 |

- **返回**：`Result<ShortLinkCreateRespDTO>`，`data` 字段：`fullShortUrl`、`originUrl`、`gid`。

#### 2.3.2 批量创建短链接（导出 Excel）

- **路径**：`POST /api/clearlink/admin/v0.1/create/batch`
- **说明**：批量创建成功后**直接返回 Excel 文件流**（`EasyExcel`），非 JSON。
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| originUrls | string[] | 是 | 原始链接集合 |
| describes | string[] | 否 | 描述集合（与 originUrls 一一对应） |
| gid | string | 是 | 分组标识 |
| createdType | int | 否 | 创建类型：0=接口 1=控制台 |
| validDateType | int | 否 | 有效期类型：0=永久 1=自定义 |
| validDate | string | 否 | 有效期，格式 `yyyy-MM-dd HH:mm:ss` |

- **返回**：Excel 文件（`.xlsx`）。

#### 2.3.3 修改短链接

- **路径**：`POST /api/clearlink/admin/v0.1/update`
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| originUrl | string | 是 | 新原始链接 |
| fullShortUrl | string | 是 | 完整短链接 |
| originGid | string | 是 | 原分组标识 |
| gid | string | 是 | 目标分组标识 |
| validDateType | int | 否 | 有效期类型：0=永久 1=自定义 |
| validDate | string | 否 | 有效期 |
| describe | string | 否 | 描述 |

- **返回**：`Result<Void>`。

#### 2.3.4 分页查询短链接

- **路径**：`GET /api/clearlink/admin/v0.1/page`
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| gid | string | 是 | 分组标识 |
| orderTag | string | 否 | 排序字段：`todayPv`/`todayUv`/`todayUip`/`totalPv`/`totalUv`/`totalUip`（缺省按创建时间倒序） |
| current | long | 否 | 当前页，从 1 开始（默认 1） |
| size | long | 否 | 每页条数（默认 10） |

- **返回**：`Result<Page<ShortLinkPageRespDTO>>`。

### 2.4 回收站管理

#### 2.4.1 移入回收站

- **路径**：`POST /api/clearlink/admin/v0.1/recycle-bin/save`
- **请求体（application/json）**：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| gid | string | 是 | 分组标识 |
| fullShortUrl | string | 是 | 完整短链接 |

- **返回**：`Result<Void>`。

#### 2.4.2 分页查询回收站

- **路径**：`GET /api/clearlink/admin/v0.1/recycle-bin/page`
- **请求参数（Query）**：`gidList`（string，可重复，分组标识集合）、`current`（long）、`size`（long）。
- **返回**：`Result<Page<ShortLinkPageRespDTO>>`。

#### 2.4.3 恢复短链接

- **路径**：`POST /api/clearlink/admin/v0.1/recycle-bin/recover`
- **请求体（application/json）**：`gid`、`fullShortUrl`（同「移入回收站」）。
- **返回**：`Result<Void>`。

#### 2.4.4 彻底删除

- **路径**：`POST /api/clearlink/admin/v0.1/recycle-bin/remove`
- **请求体（application/json）**：`gid`、`fullShortUrl`。
- **返回**：`Result<Void>`。

### 2.5 监控统计

#### 2.5.1 单个短链接监控数据

- **路径**：`GET /api/clearlink/admin/v0.1/stats`
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| fullShortUrl | string | 是 | 完整短链接 |
| gid | string | 是 | 分组标识 |
| enableStatus | int | 否 | 启用标识：0=启用 1=未启用 |
| startDate | string | 是 | 开始日期 `yyyy-MM-dd` |
| endDate | string | 是 | 结束日期 `yyyy-MM-dd` |

- **返回**：`Result<ShortLinkStatsRespDTO>`（PV/UV/UIP、地域、浏览器、OS、设备、网络等聚合数据）。

#### 2.5.2 分组短链接监控数据

- **路径**：`GET /api/clearlink/admin/v0.1/stats/group`
- **请求参数（Query）**：`gid`（是）、`startDate`（是）、`endDate`（是）。
- **返回**：`Result<ShortLinkStatsRespDTO>`。

#### 2.5.3 单个短链接访问记录

- **路径**：`GET /api/clearlink/admin/v0.1/stats/access-record`
- **请求参数（Query）**：`fullShortUrl`、`gid`、`startDate`、`endDate`、`enableStatus`、`current`、`size`。
- **返回**：`Result<Page<ShortLinkStatsAccessRecordRespDTO>>`。

#### 2.5.4 分组访问记录

- **路径**：`GET /api/clearlink/admin/v0.1/stats/access-record/group`
- **请求参数（Query）**：`gid`、`startDate`、`endDate`、`current`、`size`。
- **返回**：`Result<Page<ShortLinkStatsAccessRecordRespDTO>>`。

### 2.6 URL 标题

## 4. 短链接跳转（特殊，不经网关 /api 前缀）

#### 4.1 短链接跳转

- **路径**：`GET /{short-uri}`
- **说明**：访问短链接后 302 重定向到原始链接。`short-uri` 为创建时生成的短码。
- **示例**：`http://nurl.ink:8001/AbCd12`
- **返回**：HTTP 302 重定向；短链接不存在或已失效时重定向到 `/page/notfound`。

#### 4.2 不存在提示页

- **路径**：`GET /page/notfound`
- **返回**：HTML 页面（`notfound`）。

## 6. 错误码参考（BaseErrorCode）

| 错误码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `A000001` | 客户端错误 |
| `A000100` | 用户注册错误 |
| `A000110` | 用户名校验失败 |
| `A000111` | 用户名已存在 |
| `A000200` | 幂等 Token 为空 |
| `A000300` | 系统繁忙（限流） |
| `B000001` | 系统执行出错 |
| `B000100` | 系统执行超时 |
| `C000001` | 调用第三方服务出错 |

> 业务异常（如「短链接记录不存在」「短链接生成重复」等）通过 `ClientException`/`ServiceException` 抛出，`code` 默认取自上述枚举（未显式指定时多为 `B000001`）。
